# Как машина учится видеть

Веб-презентация мастер-класса по компьютерному зрению: путь от одного пикселя
до свёрточной нейронной сети и классификации рукописных цифр MNIST.

**Сайт:** https://nebolsinvasili.github.io/MS/

Статический сайт без бэкенда: 22 слайда, управление с клавиатуры и мыши,
режим обзора всех слайдов, полноэкранный режим.

## Быстрый старт

### Docker (рекомендуется для показа в аудитории)

```bash
docker compose up -d --build
```

Сайт: **http://localhost:8080**

Остановить:

```bash
docker compose down
```

### Доступ из локальной сети (телефоны, планшеты, другие ноутбуки)

Контейнер слушает `0.0.0.0:8080`, поэтому достаточно узнать IP своего компьютера
и раздать адрес:

```bash
hostname -I | awk '{print $1}'
```

На остальных устройствах открыть `http://<IP>:8080`.

Проверьте, что порт не блокирует файрвол:

```bash
sudo ufw allow 8080/tcp   # если используется ufw
```

### Без Docker

Любой статический сервер из корня репозитория:

```bash
python3 -m http.server 8080
```

Открывать `index.html` напрямую через `file://` не стоит — часть слайдов
использует загрузку ресурсов, которой браузер в этом режиме мешает.

## Управление

| Клавиша | Действие |
|---|---|
| `→` `↓` `Space` `PgDown` | следующий слайд |
| `←` `↑` `PgUp` | предыдущий слайд |
| `Home` / `End` | первый / последний слайд |
| `O` | режим обзора всех слайдов |
| `F` | полный экран |
| `?` | подсказка по управлению |

## Структура

```
index.html              разметка всех слайдов
css/style.css           оформление
css/fonts.css           подключение локальных шрифтов (генерируется)
js/app.js               навигация, анимации, интерактив
js/digits.js            данные примеров MNIST
assets/img/             изображения к слайдам
assets/tasks/           иллюстрации практических заданий
assets/fonts/           Manrope и JetBrains Mono (woff2)
scripts/fetch-fonts.py  обновление локальных шрифтов
nginx.conf              конфиг nginx для контейнера
```

Сайт полностью автономен: шрифты, картинки и скрипты лежат локально.
При отсутствии интернета он работает без потери оформления.

## Обновление шрифтов

Шрифты уже скачаны в `assets/fonts/`. Пересобрать при необходимости:

```bash
python3 scripts/fetch-fonts.py
```
